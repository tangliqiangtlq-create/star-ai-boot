## 依赖关系

```
后端内部：
  system-cloud-start (7001)  ←  payment/creator/stream (7010/7012/7011)
  payment-api ← stream-api ← creator-api (跨模块 Feign 调用)
  RabbitMQ: video.uploaded → video.transcode → payment.success
  所有模块 → Gateway (8080)

前端：
  star-ai-admin (3002) ←→ Gateway (8080) ←→ star-ai-app (3000)
  两者共享 Sa-Token (Redis)
  两者都走 /api/** 前缀（Vite proxy → Gateway）
```
