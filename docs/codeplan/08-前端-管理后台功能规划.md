# 管理后台功能规划（基于现有后端接口）

> 目标：在 `star-ai-admin`（Vue3 + TypeScript + Vite + Ant Design Vue 4 + Pinia）上实现管理后台。
> 对接原则：**真实接口为主，支付类（方案未定）走 Mock**。

## 0. 前置与约定

- 后端 6 服务已运行并注册 Nacos：`gateway(9999)`、`jeecg-system(7001)`、`stream(7011)`、`creator(7012)`、`payment(7010)`、`transcode-worker(7013)`。
- 前端统一经网关 `http://localhost:9999` 访问，路由前缀按服务拆分。
- 网关存在 S2S HMAC 签名校验链路（`X-Gateway-Sig`），登录链路打通前所有下游接口对外 401。
- Mock 范围：支付订单、退款、支付渠道、结算（payment 模块 AiPayment*）；数据看板趋势数据。

## 3. 后端缺口（开发前端前需补齐）

1. **订阅池 / 订阅计划管理接口**（模块 9）：表在（`stream_subscription_plan`、`stream_subscription_pool`、`stream_platform_config`），无任何 Controller，需补 CRUD + 池子余额/配置读写。
2. **创作者聚合列表接口**（模块 5）：现仅有单个 `/creators/{id}`，缺分页列表，需补 `/admin/creator/list`。
3. **提现审核动作**（模块 7）：现有通用 CRUD，建议补 `/{id}/approve`、`/{id}/reject`。
4. **数据看板聚合接口**（模块 2，可选）：可先前端聚合 + 趋势 Mock。
5. 支付订单/退款/渠道/结算 → 按约定走 **Mock**。

## 4. 实施顺序

1. 打通登录链路（S2S 签名 401）。
2. 补齐第 3 节后端缺口（订阅池、创作者列表、提现审核）。
3. 搭建管理后台骨架（路由 + 布局 + Axios 封装 + 登录页）。
4. 按第 2 节逐页实现，支付页用 Mock。
5. 逐页用 `04-三仓联调Checklist.md` 验收。
