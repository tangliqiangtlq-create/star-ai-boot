## Sa-Token 对接要点（两个前端共用）

```typescript
// request.ts / client.ts 拦截器
const token = localStorage.getItem('X-Access-Token')
if (token) {
  config.headers['X-Access-Token'] = token      // JeecgBoot 必须
  config.headers['Authorization'] = `Bearer ${token}`  // 标准格式
}
```
