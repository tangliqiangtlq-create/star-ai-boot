## 设计系统 Token

### 颜色

```css
/* 主色 —— 春楼红 (Netflix 风) */
--primary-50:  #fef2f2    /* 按钮 hover 背景 */
--primary-100: #fee2e2
--primary-500: #ef4444    /* Logo / VIP 徽章 / 重要按钮 */
--primary-600: #dc2626    /* CTA 实心按钮 */
--primary-700: #b91c1c    /* 按下态 */

/* 成功绿 —— "立即观看" */
--green-500:   #22c55e
--green-600:   #16a34a

/* 卡片背景 */
--card-bg:     #ffffff    /* 浅色 */
--card-bg-dark:#1a1a1a    /* 深色 */

/* 文字 */
--text-900:    #0a0a0a    /* 主标题 */
--text-600:    #525252    /* 正文 */
--text-400:    #a3a3a3    /* 辅助 */
--text-200:    #e5e5e5    /* 占位符 */

/* 卡片角标 */
--badge-free:  #22c55e    /* 免费 */
--badge-price: #ef4444    /* 付费价格 */
--badge-vip:   #dc2626    /* VIP 锁定 */
--badge-series:#f97316    /* 剧集打包 */
```

### 间距 & 圆角

```
间距 scale (4px grid):
  xs: 4px    sm: 8px    md: 12px    lg: 16px    xl: 24px    2xl: 32px

圆角 scale:
  sm: 4px    md: 8px    lg: 12px    xl: 16px    pill: 9999px

阴影 (卡片):
  shadow-sm: 0 1px 2px rgba(0,0,0,0.05)
  shadow-md: 0 2px 8px rgba(0,0,0,0.08)
  shadow-lg: 0 4px 16px rgba(0,0,0,0.12)
```

### 字体层级

```
Mobile (390px):
  display:   [32px, Bold]    /* Hero Banner 标题 */
  h1:        [24px, Bold]    /* 区块标题 */
  h2:        [20px, Bold]    /* 卡片标题大号 */
  body-lg:   [16px, Medium]  /* 卡片标题 */
  body:      [14px, Regular] /* 正文 */
  caption:   [12px, Regular] /* 辅助文字 */
  badge:     [10px, Bold]    /* 角标 */

PC (1440px):
  display:   [48px, Bold]
  h1:        [32px, Bold]
  h2:        [24px, Bold]
  body-lg:   [18px, Medium]
  body:      [16px, Regular]
  caption:   [14px, Regular]
```

### 断点

```
sm: 640px   /* 手机横屏 */
md: 768px   /* iPad */
lg: 1024px  /* 平板横屏 */
xl: 1280px  /* 13" 笔记本 */

```
