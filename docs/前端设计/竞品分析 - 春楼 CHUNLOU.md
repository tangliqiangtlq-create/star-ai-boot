# 竞品分析 · 春楼 CHUNLOU (chunlou.tv)

> 分析日期：2026-10-11 | 分析人：架构组 | 样本页面：`/browse`（首页+剧集库）
>
> **目的**：对标竞品的前端设计模式、消费路径、用户体验，反哺我们 榴莲 TV Boot 18+ 视频付费分润平台的前端落地。

---

## 一、产品定位快速判断

| 维度 | 春楼 CHUNLOU | 我们 榴莲 TV Boot |
|------|-------------|------------------|
| 内容来源 | 自制/签约创作者上传 | **AI 生成 + 创作者上传**双轨 |
| 年龄门槛 | 18+ 强制确认弹窗 | 18+ KYC 验证（系统级，非仅弹窗） |
| 消费模式 | **按集解锁 + VIP 会员** 两种 | **五种消费路径**（免费/全局免费集数/会员/创作者全局/剧集/单集） |
| 创作者分润 | 有"创作者推广赚现金"入口，但前端不透明 | **创作者自助定价 + 公开分润比例 + 实时收益看板** |
| 剧集结构 | 有标签 #分类 + 集数 | 有，但我们还有 series_code 多季支持 |
| 全局解锁 | ❌ 未发现 | ✅ 创作者全局解锁（global_unlock_price） |
| 全球市场 | 单语种（中文简体） | ✅ 双 Region（cn + sg/us） |

**核心差异**：春楼是典型的「单业务线」短剧付费站——只有按集买 + 会员两种消费路径，创作者定价权不开放，分润机制前端不透明。我们是「AI 生成 + 创作者生态」双轮驱动，定价权完全开放给创作者，五种消费路径叠乘以最大化转化。

### 2.2 关键前端组件

| 组件 | 春楼实现 | 我们对标 | 建议 |
|------|---------|---------|------|
| **视频卡片** | 封面图 + 标题 + 立即观看按钮 | ✅ 复用 | 加角标：💰单集 ¥15 / 🔒VIP / ✅免费 N 集 |
| **标签系统** | `#权谋 #后宫 #复仇` 井号式 | ✅ stream_video_tag 已建 | 春楼没有分类层级，我们支持 category 父类 + tag 子类 |
| **剧集信息** | `3 集 · #标签1 #标签2 #标签3` | ✅ collection_episode_count | 春楼只有集数，我们可以加 **总时长/平均单集时长** |
| **VIP 锁定态** | 封面打 🔒 + "VIP 专属" 标签 | ✅ price_type='member_only' | 建议加 **半透明遮罩 + 模糊效果 + "开通会员免费看" CTA** |
| **立即观看 CTA** | 绿色实心按钮 | ✅ | 春楼没有价格展示，我们必须展示 **试看秒数 + 价格** |
| **排行榜** | TOP 10 热度排序 | ✅ play_count 已建 | 春楼只按热度，我们可以加 **新上线榜 / 飙升榜 / 创作者榜** 多维度 |
| **创作者入口** | 底部悬浮 "加入创作者推广" | ✅ creator 模块独立 | 我们创作者入口应在首页顶部导航更突出（春楼太隐蔽） |
| **搜索** | 🔍 搜索图标 | ✅ | 春楼搜索功能未知，我们需要 **按剧名/创作者/标签** 三维搜索 |
| **顶部导航** | 按集解锁 / VIP 专享 / 全部剧集 / 排行榜 | 可优化 | 春楼导航只分消费模式，我们应该加 **创作者中心** 入口 |

### 2.3 消费路径对比（用户视角）

```
春楼的用户消费路径 (2 种):
═══════════════════════════════════════════════════════════════

用户想看某视频
  ├─ 免费: 直接看 ← 春楼基本没有免费内容
  ├─ 按集解锁: 点"立即观看" → 支付 → 永久看 ← 主要路径
  └─ VIP 专享: 封面锁 → 开会员 → 全 VIP 内容免费 ← 主要路径

春楼缺失的消费路径:
  ❌ 剧集打包解锁
  ❌ 创作者全局解锁
  ❌ 全局免费集数（拉新用）
  ❌ 会员集级/秒级扩展权益
  ❌ 充值送积分

我们的消费路径 (5 种, v1.2.1):
═══════════════════════════════════════════════════════════════

用户想看某视频 (每一步都可能命中, 首个命中即放行):
  ① free                 → 免费看
  ② 全局免费集数          → 免费看 (平台配置前 3 集)
  ③ price_type='member'  → 会员完整免费 (订阅池贡献)
  ④ 会员集级扩展          → 全局 3 + plan.free_episode_extra = 更多免费集
  ⑤ 创作者全局解锁        → 永久解锁该 creator 所有视频
  ⑥ 剧集打包解锁          → 永久解锁该剧集
  ⑦ 单集购买              → 永久解锁该单集

前端引导 (视频详情页, 用户未解锁时):
  [试看 30s]                    ← 秒级试看
  [买这一集 ¥15]                ← 单集
  [解锁整部剧集 ¥199]           ← 剧集
  [解锁该创作者全部 ¥388]       ← 全局 (global_unlock_enabled=1 时)
  [开通会员免费看 + 送 100 积分] ← 会员 (price_type='member_only' 时)
```

## 三、春楼前端设计的优缺点

### 3.1 ✅ 做得好的

| # | 优点 | 细节 | 我们可以抄 |
|---|------|------|-----------|
| 1 | **卡片式瀑布流布局** | 封面 + 标题 + CTA，简洁统一 | ✅ 首页 Feed 区用这个 |
| 2 | **标签化分类浏览** | 古风仙侠 / 现代都市丽人 / 时尚禁果 等 | ✅ 我们已有 tag 表，前端展示对齐 |
| 3 | **VIP 锁定态 UI 清晰** | 封面直接显示 "VIP" 徽章 | ✅ 加半透明遮罩 + 模糊效果更高级 |
| 4 | **排行榜突出** | TOP 10 独立区块 + 热度数字 | ✅ 加新上线榜/飙升榜多维度 |
| 5 | **Hero 轮播推荐** | 3-4 个主推荐位抓眼球 | ✅ 首页顶部保留 |

### 3.2 ❌ 明显缺失 / 我们应该做得更好的

| # | 春楼缺失 | 我们的方案 | 差异化价值 |
|---|---------|-----------|-----------|
| 1 | **没有免费内容拉新** | 全局免费集数（前 3 集所有人免费） | 转化率提升：非会员可以先看几集再决定买 |
| 2 | **只有 2 种消费路径** | 5 种消费路径叠乘以最大化转化 | 用户可以按需消费（不想买全集就买单集，不想买单集就买全局） |
| 3 | **创作者定价权不开放** | 创作者自助定价 + 区间审核 | 创作者动力更强 → 内容供给更多 |
| 4 | **全局解锁** | creator_account.global_unlock_price | 粉丝经济：用户喜欢某个创作者 → 一笔钱全部解锁 |
| 5 | **会员权益单薄（只有"畅看全集"）** | 充值送积分 + 免费集数扩展 + 试看秒数扩展 | 会员价值感更强 → 续费率高 |
| 6 | **创作者入口隐蔽（底部小按钮）** | 首页导航 + 创建者中心独立入口 | 突出我们"AI 生成 + 创作者生态"双轮驱动定位 |
| 7 | **没有试看** | preview_sec + 会员扩展 | 给用户安全感（先看再买） |
| 8 | **没有 AI 生成的差异化展示** | 首页单独区块 "AI 原创 · 榴莲 TV" | 这是我们的核心差异化，春楼没有 |
| 9 | **单语种（中文）** | cn/sg/us 三 Region 独立前端 | 国际化市场 |

## 五、后端 API 对前端的支撑点

| 前端需求 | 后端接口 | Schema 支撑 |
|---------|---------|------------|
| 视频卡片展示价格+免费集数 | `GET /stream/videos` | stream_video.price_amount + collection_rel.episode_number + stream_platform_config.free_episodes_per_series |
| 详情页解锁选项动态组合 | `GET /stream/videos/{id}` 返回 buy_options[] | 动态判断 creator.global_unlock_enabled + 是否有 series |
| 全局免费集数判断 | `GET /stream/videos/free-check` (或内嵌在详情) | stream_platform_config 读取 |
| 会员方案展示权益 | `GET /subscriptions/plans?region=cn` | stream_subscription_plan 所有权益字段 |
| 创作者展示分润比例 | `GET /creators/{id}` | creator_account.revenue_rate + subscription_revenue_rate |
| 创作者定价区间可见 | `GET /creators/pricing-bounds` (仅创作者自己) | price_amount_min/max + series_price_min/max + global_unlock_price_min/max |

## 六、技术栈建议

| 层 | 春楼推测 | 我们建议 |
|---|---------|---------|
| **框架** | 可能是 Vue 2 + Vant 或纯静态 | **React 18 + Next.js 15 (App Router)** (SSR 对 SEO 友好, 视频列表预渲染) |
| **UI 组件** | 自定义卡片 | **Tailwind CSS + shadcn/ui** (快速搭建卡片/按钮/Modal) |
| **视频播放器** | video.js 或自研 HLS | **hls.js + 自研** (签名 URL 15min 时效, 播放器要处理 token 刷新) |
| **状态管理** | 未知 | **Zustand** (轻量, 适合消费类前端) |
| **支付** | 微信/支付宝 WebView | **统一支付组件** (内部按 region 路由: cn→WX/ZFB, us→Stripe) |
| **国际化** | 无 | **i18next** (cn/zh-Hant/en, 按 region 自动切换) |
| **SSR/SSG** | 可能无 | **Next.js 混合渲染** (首页列表 SSG + 视频详情 SSR + 创作者中心 CSR) |
| **图片 CDN** | 未优化 | **直接复用 MinIO/CloudFront 签名 URL** (封面走 CDN 缓存) |

## 七、总结：我们的差异化护城河

```
春楼能做的，我们都能做。
春楼不能做的，我们要做得更好。

春楼模式                          我们模式
══════════                        ══════════
AI 内容生成        ❌ 没有          ✅ 榴莲 TV 原创专区 (核心差异化)
创作者定位         纯内容生产者      ✅ AI 合伙人 + 创作者生态
定价权             平台统一定价      ✅ 创作者自助定价 + 平台区间审核
消费路径           2 种 (按集/会员)  ✅ 5 种 (免费/全局/会员/剧集/单集)
会员权益           单一畅看         ✅ 积分 + 集级扩展 + 秒级扩展 + 充值送
试看               ❌ 没有          ✅ 30s 默认 + 会员扩展
免费内容拉新       ❌ 没            ✅ 全局免费前 3 集
国际化             单语种           ✅ cn/sg/us 三 Region 独立前端
创作者分润透明      ❌ 前端不展示    ✅ 公开分润比例 + 实时看板 + 抽成快照
```

**一句话总结**：春楼是一个传统的短剧付费站，我们是一个「AI 生成 + 创作者生态」双轮驱动、定价权完全开放给创作者、五重消费路径叠乘以最大化转化、双 Region 国际化的新一代内容平台。在前端体验上，**视频详情页的解锁选项动态组合** + **创作者中心的定价透明化** + **AI 原创专区的差异化展示** 这三件事是春楼做不到、也是用户一眼能感知到的核心差异点。
