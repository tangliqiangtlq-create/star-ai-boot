| 层级 | 选型 | 部署方式 | 费用 |

### ④ 多媒体分享矩阵 · $3,500

> 💡 18+ 内容平台最核心的增长武器——让用户/创作者一键把视频切片、海报、GIF 分发到所有主流社交平台，带邀请码追踪，自动结算佣金。

| 编号 | 功能 | 说明 |
|------|------|------|
| 4.1 | 视频一键转码（多规格） | 用户点击「分享」→ 后台自动生成：**原片 1080p / 竖屏 9:16 1080×1920（适合 TikTok/Reels）/ 方形 1:1 1080×1080（适合 Instagram）/ 低码率 360p（适合 Telegram 快速加载）** |
| 4.2 | 自动切片 + 高光提取 | AI 自动识别视频高潮片段（语速最快 + 画面最密集 + 互动数据最高的时间窗）→ 生成 15-30 秒高光 Reel · 支持创作者手动选择片段 |
| 4.3 | GIF 自动生成 | 支持将视频关键帧序列 / 高光片段自动生成 **5-10 秒循环 GIF** · 压缩到 2MB 以内 · 适合 Discord / Reddit / Twitter 贴图传播 |
| 4.4 | 海报自动生成 | 自动截取视频高光帧 + 叠加标题 + 价格角标 + **用户邀请码二维码** · 3 套模板后台可配置（简约 / 潮流 / 复古） |
| 4.5 | 多平台一键分发 | **App 内置 Share Sheet** · 支持一键发送到：Twitter/X · Telegram · Discord · Reddit · TikTok · Instagram · YouTube Shorts · Threads · WhatsApp · Signal · 微信（海外版 WeChat） |
| 4.6 | 分享链接追踪 | 每个分享链接自动嵌入 **用户邀请码 + UTM 参数 + 内容 ID + 时间戳** · 分享带来的注册 / 付费自动归因到分享者 |
| 4.7 | 分享数据看板 | 用户中心：分享次数 / 各平台分布 / 点击量 / 带来注册数 / 带来付费金额 / 累计佣金 |
| 4.8 | 版权保护（暗水印） | 生成的分享视频自动嵌入**不可见数字水印**（携带分享者 ID + 内容 ID + 时间戳）· 被盗后可溯源追责 |

**技术栈**：ffmpeg（转码 / 切片 / GIF / 海报）+ OpenCV（高光帧提取）+ Pillow（海报合成）+ **Share Sheet API（Capacitor 原生）** + CDN（多规格转码缓存）

**分享流程**：
```
用户 A 看视频 → 点「分享」→ 选择平台 →
   ├→ 自动生成：多规格视频 + GIF + 海报 + 带邀请码的短链接
   ├→ 用户选择目标平台（如 Telegram）
   ├→ 自动调用 Capacitor Share Sheet 唤起 Telegram
   └→ 分享成功后：
         · 分享到 Telegram 带来的有效播放（≥30秒）→ A 得 50 积分/次
         · 带来新用户注册 → A 得 $0.5 邀请奖励
         · 带来新用户付费 → A 得 30% 佣金（与推广系统三级分销合并计算）
```

## 六、不含项（重要）

- ❌ **AI 编辑器 / AI 剧本生成 / AI 视频合成**（主项目已明确不含）
- ❌ **深度学习大模型推荐**（本升级包采用轻量协同过滤，大模型推荐可后续升级）
- ❌ **ASR / 翻译 API 调用费用**（客户自行申请 Whisper API / DeepL API 等，按量付费）
- ❌ **APNs 证书 / FCM 项目配置**（客户自行申请，我方提供配置文档）
- ❌ **ffmpeg 转码服务器集群**（多媒体分享矩阵会消耗较多 CPU，建议至少 2 台 8C16G 服务器）
- ❌ **服务器扩容 / Redis 集群 / CDN 升级**（升级包上线可能需要额外服务器资源）
- ❌ **链上 Gas 费**（USDT/USDC 自动打款产生的 Gas 费，从推广佣金池扣除或平台承担）
- ❌ **运营素材设计**（推广海报 Banner / 成就徽章图标等视觉设计）
- ❌ **App Store / Google Play 审核**（升级包涉及推送权限与原生分享，需客户自行更新 App 版本提交审核）
