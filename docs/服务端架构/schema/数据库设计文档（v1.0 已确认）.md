## 一、设计规范

所有表统一遵循以下约定：

| 约定 | 说明 |
|------|------|
| **主键** | `BIGINT UNSIGNED`，雪花 ID（不依赖数据库自增） |
| **多租户** | 所有业务表带 `tenant_id BIGINT UNSIGNED NOT NULL`，MyBatis-Plus 自动注入 `WHERE tenant_id = ?`；`tenant_id = 0` 表示平台级/系统级（不隔离） |
| **软删除** | `del_flag TINYINT NOT NULL DEFAULT 0`（0=存在, 1=已删除），查询统一追加 `AND del_flag = 0` |
| **乐观锁** | `revision INT UNSIGNED NOT NULL DEFAULT 0`，UPDATE 时自动 `revision = revision + 1` + `WHERE revision = 旧值` |
| **审计字段** | `create_by / create_time / update_by / update_time`，`create_time` 默认 `CURRENT_TIMESTAMP(3)`，`update_time` 自动更新 |
| **扩展字段** | `ext_json JSON DEFAULT NULL`，灵活存放不常查询的扩展配置，避免频繁 DDL |
| **时间精度** | 统一 `DATETIME(3)`，毫秒级，时区 UTC+8 |
| **金额** | 统一 `DECIMAL(12,4)`，避免浮点精度问题 |
| **敏感字段** | 手机号 / 邮箱 / AK / SK / Token / 密码 Hash → AES-256-GCM-SIV 加密后存储，Mybatis TypeHandler 自动加解密 |
| **索引** | 业务外键、`tenant_id + 核心查询字段` 复合索引、唯一约束带 `del_flag` 防删除后冲突 |

### 🔐 加密字段清单（统一走 AES-256-GCM-SIV）

| 表 | 字段 | 场景 |
|----|------|------|
| sys_user | password | PBKDF2 哈希后存储 |
| sys_user | phone / email | 通信敏感信息 |
| sys_tenant | contact_phone | 租户联系方式 |
| sys_user_mfa | secret_hash | MFA 密钥不可逆 Hash |
| sys_user_agent | ip_hash | IP 哈希 |
| ai_channel | ak_cipher / sk_cipher | AI 供应商凭证（**最敏感**） |
| ai_channel | encryption_key_ref | KMS Key ID 引用 |

## 三、分域详细设计

### 3.1 系统管理域 `sys_*`（13 张表）

| contact_name | VARCHAR(50) | YES | - | 联系人 |

| contact_email | VARCHAR(128) | YES | - | 联系邮箱（**加密**） |

#### 3.1.3 sys_user_tenant 用户-租户关联

#### 3.1.4 sys_role 角色

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| tenant_id | BIGINT | 租户（**0=平台级角色**，所有租户可用） |

---

#### 3.1.6 关联表：sys_user_role / sys_role_permission

标准 N:N 关联表，三列（user_id + role_id + tenant_id），tenant_id 用于区分不同租户下同一用户拥有的不同角色。

---

#### 3.1.7 sys_permission_data_rule 数据权限规则

**用途**：行级数据权限（`WHERE create_by = current_user_id` 这类规则）。

| 字段 | 类型 | 说明 |
|------|------|------|
| role_id | BIGINT | 角色（必选） |
| permission_id | BIGINT | 权限（**NULL = 该角色全局生效**） |
| rule_column | VARCHAR(100) | 过滤字段（如 `tenant_id`, `create_by`, `dept_id`） |
| rule_operator | VARCHAR(10) | `=`, `!=`, `IN`, `LIKE`, `BETWEEN` |
| rule_value | VARCHAR(500) | 过滤值（支持 `${current_user_id}` 等变量） |
| priority | INT | 优先级（小优先） |

**索引**：`INDEX(role_id)` / `INDEX(permission_id)`

---

#### 3.1.8 sys_user_mfa 用户 MFA 配置

| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | BIGINT | 用户 |
| mfa_type | TINYINT | **1=TOTP, 2=Email OTP, 3=WebAuthn, 4=SMS** |
| secret_hash | VARCHAR(255) | 密钥**不可逆 Hash**（OTP Hasher） |
| backup_codes_hash | VARCHAR(2000) | 备用码 Hash（JSON 数组，已使用的移除） |
| recovery_email | VARCHAR(128) | 恢复邮箱 |
| last_verify_time | DATETIME(3) | 最后验证时间 |
| enabled | TINYINT | 0=禁用, 1=启用 |

**索引**：`UNIQUE(user_id, mfa_type, del_flag)`

---

#### 3.1.9 sys_user_agent 用户可信设备

**用途**：WebAuthn / 浏览器指纹 / IP 异常检测。

| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | BIGINT | 用户 |
| device_name | VARCHAR(100) | 用户可自定义名称 |
| device_type | VARCHAR(30) | mobile / pc / tablet / unknown |
| user_agent / fingerprint | VARCHAR(500/128) | 指纹信息 |
| webauthn_id / webauthn_public_key | VARCHAR(255) / TEXT | WebAuthn 凭证 |
| ip_hash | VARCHAR(128) | IP **哈希存储**（加密，不可反查） |
| is_trusted | TINYINT | **0=未验证, 1=已信任, 2=已拒绝** |
| last_use_time | DATETIME(3) | 最后使用 |

**索引**：`INDEX(user_id)` / `INDEX(fingerprint)` / `INDEX(webauthn_id)`

---

#### 3.1.10 sys_log / sys_data_log

**sys_log**：操作审计日志（谁、什么时候、调了什么接口、耗时、IP、结果）

| 字段 | 说明 |
|------|------|
| tenant_id / user_id / username | 操作人（username 冗余便于直接查） |
| module_name | 模块名 |
| operation | 操作描述（如"删除用户 admin"） |
| method | 全限定类名+方法 |
| request_method / request_url | HTTP 信息 |
| request_param / response_result | **脱敏后**的请求/响应 |
| ip / location / device | 客户端信息 |
| status | 0=失败, 1=成功 |
| cost_ms | 耗时毫秒 |
| exception_msg | 异常栈（脱敏） |
| trace_id | 链路追踪 |

**sys_data_log**：数据变更日志（`@DataLog` 拦截 UPDATE/INSERT/DELETE）

| 字段 | 说明 |
|------|------|
| data_source / table_name / pk_id | 定位哪张表的哪条记录 |
| action | 1=INSERT, 2=UPDATE, 3=DELETE |
| old_value / new_value / diff_json | JSON 格式，diff_json 只存变更字段 |
| operator_id / operator_name / operator_ip | 操作人 |
| trace_id / create_time | - |

**索引**：sys_log `INDEX(tenant_id, create_time)` / sys_data_log `INDEX(table_name, pk_id)`

---

#### 3.1.11 sys_dict / sys_dict_item

字典表（`@Dict` 注解自动翻译），**平台级和租户级**字典混合（`tenant_id = 0` 为平台共享）。

sys_dict_item 含 `item_code / item_text / item_value / item_color / sort_no`，支持树形字典（通过 parent_id 扩展）。

### 3.2 AI 供应商域 `ai_*`（4 张表）

#### ER

```
ai_provider (平台级, 只读)
    │ 1:N
    ▼
ai_model    (平台级, 只读)

    │ N:M (通过 ai_channel_model)
```

---

#### 3.2.1 ai_provider 供应商

**只读**，平台级配置，不允许租户修改。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| provider_code | VARCHAR(64) | **唯一编码**：bytedance / aliyun / kling / openai / google |
| provider_name_cn | VARCHAR(50) | 中文名 |
| provider_name_en | VARCHAR(50) | 英文名 |
| api_base_url | VARCHAR(300) | API Base URL |
| auth_type | TINYINT | **0=Bearer, 1=AK-SK签名, 2=OAuth, 3=自定义** |
| default_timeout_ms | INT | 默认超时 60000ms |
| default_retry | TINYINT | 默认重试 2 次 |
| default_retry_interval_ms | INT | 默认重试间隔 1000ms |
| api_docs_url / website_url | VARCHAR(500) | 文档/官网 |
| ext_json | JSON | 扩展：签名算法、Header 模板、SSE 格式等 |
| status | TINYINT | 0=禁用, 1=正常, 2=灰度 |

**索引**：`UNIQUE(provider_code, del_flag)`

---

#### 3.2.2 ai_model AI 模型

**只读**，平台级，一个 provider 下多个 model。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| provider_id | BIGINT | 外键 → ai_provider |

| model_category | VARCHAR(30) | **text / image / video / audio** |

| input_types | JSON | 输入类型列表 `["text","image"]` |
| output_types | JSON | 输出类型列表 `["video"]` |
| default_resolution / supported_resolutions | VARCHAR(30) / JSON | 分辨率支持 |
| max_duration_sec | INT | 最大生成时长（秒） |
| supports_multi_ref | TINYINT | 多参考图支持 |

| estimated_duration_sec | INT | 预估生成时长 |
| qpd_limit | INT | 厂商每日配额 |
| ext_json | JSON | 推荐参数、Prompt 模板 |
| status / sort_no | - | - |

**索引**：`UNIQUE(provider_id, model_id, del_flag)` / `INDEX(task_type)` / `INDEX(model_category)`

#### 3.2.3 ai_channel AI 通道（租户级，凭证存放表）

**最敏感表**：存放 AK/SK（AES-256-GCM-SIV 加密），每个租户可以为同一个 Provider 配置多个通道（主备 + 负载）。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| tenant_id | BIGINT | 租户（**0=平台共享通道**） |
| provider_id | BIGINT | 外键 → ai_provider |
| channel_name | VARCHAR(100) | 通道名称（如"火山-主通道"） |
| **ak_cipher** | VARCHAR(512) | **AccessKey，AES-256-GCM-SIV 加密** |
| **sk_cipher** | VARCHAR(1024) | **SecretKey，AES-256-GCM-SIV 加密** |
| encryption_key_ref | VARCHAR(100) | 密钥引用（KMS Key ID / 本地 Key 标识） |
| api_base_url_override | VARCHAR(300) | 覆盖 Provider 默认 URL（代理/私有部署） |
| weight | INT | 负载权重（默认 100） |
| priority | INT | 优先级（数值越小越优先） |
| quota_per_day / quota_used_today / quota_reset_time | INT / INT / DATETIME | 日配额控制 |
| health_status | TINYINT | **0=offline, 1=healthy, 2=degraded, 3=circuit_breaker** |
| consecutive_failures | INT | 连续失败次数（自动熔断） |
| rate_limit_per_minute | INT | 每分钟速率限制 |
| enabled / expire_time / last_used_time | - | - |

**索引**：`INDEX(tenant_id, provider_id)` / `INDEX(health_status)`

#### 3.2.4 ai_channel_model 通道-模型绑定

| 字段 | 类型 | 说明 |
|------|------|------|
| channel_id | BIGINT | 通道 |
| model_id | BIGINT | 模型 |
| custom_price_per_sec | DECIMAL(12,8) | 通道专属价格（NULL=用平台默认） |
| enabled | TINYINT | 0=禁用, 1=启用 |

**索引**：`UNIQUE(channel_id, model_id)`

### 3.3 内容创作域 `ai_*`（5 张表）

#### ER

```
ai_asset_library (角色库/场景库/道具库/抽帧库...)
    │ 1:N
    ▼
ai_asset          (图片/视频/音频/角色/场景/道具)

ai_script         (AI 生成的剧本)
    │ 1:N
    ▼
ai_storyboard_project  (分镜项目 = 时间线容器)
    │ 1:N
    ▼
ai_storyboard_shot     (单个镜头 ← 引用多个 ai_asset)
    │ N:1
    ▼
ai_generation      (视频生成记录, 见 3.4)
```

---

#### 3.3.1 ai_asset_library 素材库分类

| 字段 | 类型 | 说明 |
|------|------|------|
| tenant_id | BIGINT | 租户 |
| library_name | VARCHAR(100) | 如"角色库"/"场景库" |
| library_type | VARCHAR(30) | **character / scene / prop / frameasset / virtual / custom** |
| cover_url | VARCHAR(500) | 封面 |
| is_public | TINYINT | 0=私有, 1=租户共享, 2=平台公开 |

**索引**：`INDEX(tenant_id, library_type)`

#### 3.5.1 ai_billing 账户钱包

**一条 user_id + tenant_id 只有一行**，记录余额、冻结金额、累计统计。

| 字段 | 类型 | 说明 |

**⚠️ 关键设计点**：充值/扣费**必须走悲观锁或 UPDATE version CAS**，不能简单 `UPDATE SET balance = balance - ?`。建议：

```sql
UPDATE ai_billing
SET credits_balance = credits_balance - ?,
    credits_frozen  = credits_frozen  - ?,
    version = version + 1
WHERE id = ? AND version = ? AND credits_balance >= ?
```

#### 3.5.6 ai_team / ai_team_member / ai_team_role_permission / ai_team_budget_log

**ai_team**：**团队 ≠ 租户**，是租户内的组织单元（租户已经对应一个 SaaS 客户，团队是客户内部的部门/小组）。

**ai_team_role_permission**：团队**自定义 RBAC**。团队可以定义自己的角色和权限点（不影响平台级 sys_role）。结构同 sys_role_permission，但 owner 永远有全量权限。

**ai_team_budget_log**：团队预算流水（月度重置 / 成员扣费合计 / 预算调整），结构类似 ai_usage_record。
