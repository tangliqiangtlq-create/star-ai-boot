# 安全架构

> Star AI Boot 在 JeecgBoot 原始安全体系之上，实施了 **纵深防御（Defense in Depth）** 策略，覆盖 OWASP Top 10 全场景。

---

## 一、安全分层架构

```
┌─────────────────────────────────────────────────────────┐
│  Layer 1 · 网络边界                                      │
│  CSP / HSTS / Frame-Options / CORS / RateLimit          │
├─────────────────────────────────────────────────────────┤
│  Layer 2 · API 网关层                                    │
│  Sentinel 限流 + InternalPathDeny + Token 过滤 + S2S    │
├─────────────────────────────────────────────────────────┤
│  Layer 3 · Web 应用层                                    │
│  XSS Filter / SSRF 校验 / SQL 防火墙 / Freemarker 沙箱  │
├─────────────────────────────────────────────────────────┤
│  Layer 4 · 认证授权层                                    │
│  Sa-Token JWT + 2FA/MFA + RBAC + 二次认证 + 代登录审计   │
├─────────────────────────────────────────────────────────┤
│  Layer 5 · 数据安全层                                    │
│  AES-256-GCM-SIV 加密 + 脱敏 + SQL 注入防护 + 审计日志  │
└─────────────────────────────────────────────────────────┘
```

## 二、网关安全（Layer 1-2）

### 2.1 网关安全过滤器链

```java
// star-ai-cloud-gateway · org.jeecg.filter
GlobalAccessTokenFilter           ← JWT Token 校验 + 过期刷新
InternalPathDenyFilter            ← 拦截 /internal/** 等内部路径
InternalSysApiBlockWebFilter      ← 拦截系统 API 未授权访问
ApiServiceRouteWebFilter           ← API 服务路由校验
SecurityHeadersGlobalWebFilter    ← 全局注入安全响应头
GatewayForwardedHeadersSanitizerFilter  ← 清洗 Forwarded 头
GatewaySignatureWriteFilter       ← 内部 S2S 签名写入
```

### 2.2 关键安全响应头

| Header | 值 | 说明 |
|--------|-----|------|
| `Content-Security-Policy` | Enforce 模式，`enforceTrafficPct:100` | 防止 XSS 和数据注入 |
| `Strict-Transport-Security` | `max-age=63072000; includeSubDomains; preload` | 强制 HTTPS 两年 |
| `X-Frame-Options` | `DENY` | 禁止 iframe 嵌入 |
| `Permissions-Policy` | camera/microphone/geolocation=() | 禁用高风险浏览器 API |
| `X-Content-Type-Options` | `nosniff` | 防止 MIME 嗅探 |

### 2.3 Sentinel 限流数据源（Nacos）

| DataId | 规则类型 | 场景 |
|--------|---------|------|
| `{service}-flow-rules` | Flow | QPS 限流 |
| `{service}-degrade-rules` | Degrade | 熔断降级 |
| `{service}-system-rules` | System | 系统保护 |
| `{service}-authority-rules` | Authority | 黑白名单 |
| `{service}-param-rules` | ParamFlow | 参数限流 |

### 4.3 RBAC 权限模型

```
User ──N:N── Role ──N:N── Permission
  │                               │
  └──N:N── Depart ──N:N── DepartRole ──N:N── DepartRolePermission
  └──N:N── Tenant ──N:1── TenantPack ──N:N── TenantPackUser
  └──1:1── UserMfa              └──N:N── TeamRole
  └──1:1── UserAgent (可信设备)    └──N:N── TeamRolePermission
                                     └──N:N── PortalPermissionTagDef
```

| 实体 | 说明 |
|------|------|
| `SysPermission` | 菜单 + 按钮权限 |
| `SysRolePermission` | 角色-权限关联 |
| `SysDepartRole` | 部门角色 |
| `SysUserRole` / `SysUserDepart` | 用户-角色/部门关联 |
| `SysPermissionDataRule` | 数据权限规则（行级过滤） |
| `SysTenant` + `SysTenantPack` | 多租户套餐 |
| `PortalTeamRoleDef` + `PortalTeamRolePermission` | 团队自定义 RBAC |
| `PortalPermissionTagDef` | 权限标签 |

## 六、启动期安全扫描

项目引入多道 **启动期安全验证器**，在应用启动时发现安全配置缺陷并快速失败（Fail-Fast）：

```java
// star-ai-boot-base-core
H8DenyAuditStartupVerifier        ← 启动期验证禁止审计配置完整性
H2FeignLevelStartupVerifier       ← Feign 安全级别校验
E5TemplateRenderGuardAspect       ← Freemarker 模板安全启动期验证
A9SysApiFailClosedGuard           ← 系统 API 失败即关闭守卫

// star-ai-cloud-gateway
GatewayHardeningStartupConfig     ← 网关安全启动校验
```

启动失败条件（示例）：
- `OTP_PEPPER` 未设置或长度 < 32 字符
- `SESSION_COOKIE_SECURE=true` 但 SSL 证书异常
- Nacos 中 Sentinel 规则未配置
- AK/SK 以明文形式存储

## 八、安全流程图 - 一次受保护的 API 调用

```
Client Request
      │
      ▼
┌─ Gateway ─────────────────────────────────────────────────────┐
│  ① SecurityHeadersGlobalWebFilter   ← 注入 CSP/HSTS/CORS     │
│  ② Sentinel Flow Degrade            ← QPS 限流/熔断          │
│  ③ InternalPathDenyFilter           ← /internal/** 拦截      │
│  ④ GatewayForwardedHeadersSanitizer  ← Forwarded 头清洗       │
│  ⑤ GlobalAccessTokenFilter          ← JWT + Tenant 解析      │
└────────────────────────┬──────────────────────────────────────┘
                         │
                         ▼
┌─ Business Service ─────────────────────────────────────────────┐
│  ⑥ ContentValidator                 ← 请求体校验             │
│  ⑦ TenantContextInboundFilter       ← Tenant ThreadLocal     │
│  ⑧ ApiInputXssFilter               ← XSS 清洗              │
│  ⑨ Spring Interceptor               ← Sa-Token 权限校验       │
│  ⑩ @RequireSecondAuth               ← 二次认证 (可选)        │
│  ⑪ MyBatis-Plus TenantParser        ← SQL 自动注入 tenant_id│
│  ⑫ Druid Wall Filter                ← SQL 防火墙            │
│  ⑬ @AutoLog / @Sensitive            ← 审计 + 脱敏           │
└────────────────────────┬──────────────────────────────────────┘
                         │
                         ▼
              业务逻辑执行 → 返回 Response
                         │
                         ▼
┌─ Response Layer ───────────────────────────────────────────────┐
│  ⑭ EncryptResponseAdvice            ← 响应加密 (可选)        │
│  ⑮ PrivacyCacheControlFilter        ← Cache-Control:no-store│
│  ⑯ @AutoDict                        ← 字典翻译 + 脱敏      │
└────────────────────────────────────────────────────────────────┘
```
