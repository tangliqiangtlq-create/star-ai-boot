## 二、核心扩展点

### 2.1 统一异常处理

```java
// GlobalExceptionHandler
// 所有 Controller 层异常自动转换为 Result.error()
// 分级处理：
//   JeecgBootException          → 业务异常 (code=500)
//   JeecgBootBizTipException   → 业务提示 (message 直接返回前端)
//   JeecgBoot401Exception      → 鉴权异常 (code=401)
//   JeecgSqlInjectionException → SQL 注入 (code=403 + 审计日志)
//   LedgerSecurityException    → 安全事件 (code=403 + 审计日志)
//   FProposalStatusException   → 业务状态机异常
//   E5RejectException          → 拒绝模板渲染 (Freemarker 沙箱触发)
//   FBizSemRequiredException   → 必填字段缺失
//   未知 Exception             → code=500, message="系统繁忙" + traceId
```

### 2.2 统一返回结构

```java
public class Result<T> {
    private Integer code;      // 200=成功, 401=未登录, 403=禁止, 500=错误
    private String message;
    private T result;          // 业务数据
    private Boolean success;
    private Long timestamp;
    private String traceId;    // ★ 链路追踪 ID（网关注入）
}
```

### 2.3 QueryGenerator 动态查询

```java
// 基于请求参数自动构建 MyBatis-Plus QueryWrapper
// URL 参数: col=create_time&op=between&start=2024-01-01&end=2024-12-31
// 转换为: queryWrapper.between("create_time", "2024-01-01", "2024-12-31")

// 支持的操作符 (QueryRuleEnum)：
//   eq / ne / gt / ge / lt / le / like / in / not_in / between
// 自动类型转换 (String → Date / Integer / Long)
// 自动应用 TenantLineHandler
// ★ SQL 注入防护：op 白名单 + 字段名白名单
```

### 2.4 AutoLog 自动日志

### 2.5 DictAspect 字典翻译

```java

```

### 2.6 PasswordUtil 安全密码

```java
// PBKDF2WithHmacSHA256 + 600,000 iterations
// 比 bcrypt/scrypt 更抗 GPU 暴力破解
// 配置: crypto.pbkdf2.iterations: 600000

String hashed = PasswordUtil.hash(password);     // 返回: ${pbkdf2}$${salt}$${hash}$${iterations}
boolean match = PasswordUtil.verify(password, hashed);
```

### 2.7 AesEncryptUtil / E9AesGcmSivCipher

```java
// 敏感字段加密：AES-256-GCM-SIV (NIST 推荐)
// 特性：
//   ① 认证加密：同时保证机密性 + 完整性
//   ② SIV Nonce：确定性加密 (相同明文 + 相同 key → 相同密文前缀)，便于索引查询
//   ③ 防重放攻击

// 用法
String ciphertext = AesEncryptUtil.encrypt(plaintext, key);
String plaintext  = AesEncryptUtil.decrypt(ciphertext, key);

// Mybatis TypeHandler: EncryptedString
// 数据库存密文 → Java 对象自动解密
// 写操作自动加密
```

### 2.8 OTP Hasher

```java
// OTP 哈希存储：防止数据库泄露后直接还原原始 OTP
// 算法: SHA-256(otp + pepper + userSalt)

String hashed  = OtpCodeGenerator.hash(otp, userSalt);
boolean verify = OtpCodeGenerator.verify(otp, hashed, userSalt);
// otp.pepper: ≥32 字符随机值 (环境变量注入，绝对不硬编码)
```

## 三、starter-secrets 模块

`star-ai-boot-starter-secrets` 提供 Spring Boot Environment 启动前的解密能力。

### 3.1 启动链

```
Spring Boot 启动
  │
  ▼
EnvironmentPostProcessor 阶段 (application.yml 加载前)
  │
  ├── RepoRootDotEnvEnvironmentPostProcessor
  │   └── 加载仓库根目录 .env 文件 (开发期)
  │
  └── MpaySecretsEnvironmentPostProcessor
      ├── 读取 jeecg_database.properties.enc (加密)
      ├── 调用 Secrets Decryptor
      │   ├── LocalAesGcmSecretsCrypto (AES-GCM-SIV, 本地 key)
      │   ├── AwsKmsDecryptor (AWS KMS, 生产首选)
      │   ├── HttpJsonKmsDecryptor (HTTP KMS API)
      │   ├── MpayKmsDecryptor
      │   └── HuaweiCsmsKmsDecryptor (华为云 CSMS)
      └── 注入 Spring Environment
          → application.yml 中 ${SPRING_DATASOURCE_PASSWORD} 等引用解密值
```

### 3.2 Secrets 优先级

```
1. 环境变量 SPRING_DATASOURCE_PASSWORD (K8s Secret 注入)
2. MpaySecretsEnvironmentPostProcessor 解密值
3. application.yml Nacos 远程配置
4. application.yml 本地默认值 (仅 dev)
```

```
  ▼

  │
  ▼

  │
  ▼

  │
  ▼
```

## 五、Feign 安全配置

```java
// NewFeignConfig (star-ai-system-cloud-start)
// 所有微服务间 Feign 调用自动注入认证信息
```

## 六、可扩展点

### 6.1 新增业务微服务

```
Step 1: 继承 star-ai-boot-base-core (自动获得安全/日志/字典/租户)
Step 2: 创建 {module}-api 模块 (Feign DTO + 接口定义)
Step 3: 创建 {module}-biz 模块 (实现 + 启动类)
Step 4: pom.xml 中添加:
          <dependency>org.jeecgframework.boot:star-ai-boot-base-core</dependency>
          <dependency>org.jeecgframework.boot:star-ai-module-system-cloud-api</dependency>
          <dependency>com.alibaba.cloud:spring-cloud-starter-alibaba-nacos-discovery</dependency>
Step 5: Nacos 中创建 {module}-dev.yaml / {module}-prod.yaml
Step 6: Gateway 路由表 sys_gateway_route 添加新路由
Step 7: Sentinel 规则 DataId 添加新服务
Step 8: Dockerfile + K8s Deployment
```

### 6.2 新增安全过滤器

```java
@Component
@Order(Ordered.HIGHEST_PRECEDENCE + 100)
```
